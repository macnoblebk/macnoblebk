### [CodeBreaker](https://github.com/macnoblebk/CodeBreaker)  
**A Mastermind-inspired code-breaking puzzle game built with SwiftUI and SwiftData**  

Features:  
- Classic Mastermind gameplay with customizable code lengths (3-6 pegs) 
- SwiftData persistence with automatic state saving
- Multi-game management with search, sort, and filter
- JSON export and import
- Gesture controls (rotation and pinch)
- Animated transitions and custom diamond-shaped pegs

### [NotFlix](https://github.com/macnoblebk/NotFlix)  
**A SwiftUI iOS app for browsing trending and top-rated movies and TV shows powered by the TMDB API, with YouTube trailer playback, search, and offline downloads via SwiftData.**  

Features:  
- Browse trending and top-rated movies and TV shows
- YouTube trailer playback
- Search movies and TV shows with debounced input
- Save titles for offline viewing with SwiftData
- Concurrent API fetching for fast load times
